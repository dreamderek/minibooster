# MetaMath 多選題練習頁需求整理版

## 1. 專案目的

建立一個可在手機上操作的數學多選題練習頁，提供以下流程：

- 題目閱讀
- 多選作答
- 檢討與回饋

頁面採單頁式介面，透過左右滑動在「作答頁」與「檢討頁」之間切換。

---

## 2. 頁面結構

### 2.1 頂部表頭

- 顯示品牌名稱 `MetaMath`
- 提供兩個切換按鈕：
  - 作答頁
  - 檢討頁

### 2.2 作答頁

作答頁包含：

- 題目區
- 選項區
- 送出按鈕

### 2.3 檢討頁

檢討頁包含：

- 每個選項是否正確
- 每個選項是否勾選
- 對應的預設批改文字

---

## 3. 功能需求

### 3.1 題庫載入

- 頁面啟動時直接讀取 `data/questions` 資料夾內 `q001.json` 至 `q999.json` 格式的題目檔，再隨機選出一題；不存在的編號檔會略過，因此題目檔可跳號或刪除
- `q000.json` 為空白範本，不納入題庫
- 載入失敗時顯示錯誤訊息
- 載入成功後才可開始作答

### 3.2 題目顯示

- 題目支援一般文字與數學排版
- 題目上方需顯示 meta 標籤
- 題目與選項內容可支援數學公式渲染

### 3.3 選項作答

- 每個選項使用 `checkbox`
- 允許多選
- 每個選項至少需顯示：
  - 選項代號
  - 選項文字

### 3.4 送出與檢查

- 使用者未勾選任何答案時，不可直接進入檢討頁
- 按下送出後，系統依題目資料比對作答狀態
- 送出後自動切換到檢討頁

### 3.5 檢討頁需求

檢討頁需分開顯示：

- 每個選項是否正確
- 每個選項是否勾選

不合併成單一 4 種狀態，而是採用兩個資訊分開呈現的方式。

### 3.6 取消評分機制

- 不再使用分數計算作為主要判定標準
- 檢討頁以逐項回饋為主
- 預設批改內容由資料檔案提供

---

## 4. 資料格式需求

### 4.1 題目檔規格

`data/questions/qNNN.json` 需包含：

- 題目
- 選項（預設 5 項）
- 批改對照內容

範例：

```json
{
  "title": "題目文字",
  "meta": ["標籤1", "標籤2"],
  "options": [
    { "id": "A", "text": "選項內容", "correct": true },
    { "id": "B", "text": "選項內容", "correct": true },
    { "id": "C", "text": "選項內容", "correct": false },
    { "id": "D", "text": "選項內容", "correct": false },
    { "id": "E", "text": "選項內容", "correct": false }
  ],
  "grading": {
    "A": "批改內容 A",
    "B": "批改內容 B",
    "AB": "批改內容 AB"
  }
}
```

### 4.2 資料定義

- `title`：題目主文
- `meta`：題目標籤
- `options`：選項陣列
  - 每個選項至少包含：
    - `id`
    - `text`
    - `correct`
- `grading`：作答組合對應的預設批改內容

---

## 5. 視覺與互動需求

### 5.1 版面

- 以手機尺寸優先設計
- 內容需可在小螢幕上正常閱讀
- 整體版面不可捲動，各功能區可垂直捲動
- 左右滑動可切換頁面

### 5.2 框線與標題

- 題目區、選項區、檢討區皆需顯示有標題的框線元件
- 標題需浮在框線外側
- 標題與內容區底色需一致
- 同一套框線與標題樣式需共用

### 5.3 狀態回饋

- 未作答就送出時，題目區需有明顯提示效果
- 檢討頁需讓使用者快速看出對錯與勾選狀態

---

## 6. 自訂元件需求

### 6.1 `frame-panel`

框線與標題效果需封裝成獨立自訂元件。

元件需求：

- 以 `title` 屬性設定標題文字
- 元件內部自行繪製框線
- 標題需跨在框線外側
- 標題底色需與內容底色一致
- 元件需保留 `shake` 動畫能力
- 以 `div` 包裝內容，避免外部干擾顯示

### 6.2 使用方式

- 題目區、選項區、檢討區皆應使用同一個元件
- 外層頁面只負責放入內容，不重複寫框線與標題邏輯

---

## 7. 數學渲染需求

- 題目與選項內容支援數學公式渲染
- 需支援 `MathJax` 或同等渲染方式
- 題目與選項內容可含有 LaTeX 格式

---

## 8. 驗收準則

- 可直接從 `data/questions` 載入題目檔並隨機顯示題目
- 可正確顯示題目與選項內容
- 可支援多選作答
- 未作答直接送出時會顯示明確提示
- 送出後可自動切換到檢討頁
- 檢討頁能分開顯示每個選項的正確性與是否勾選
- 版面可於手機尺寸下正常閱讀
